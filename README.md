## Общее описание

Эмулятор командной оболочки с графическим интерфейсом (GUI).
Имитирует работу командной строки UNIX-подобной ОС.
Работает с виртуальной файловой системой (VFS), загружаемой из ZIP-архива.

**Стек:** Python 3, Tkinter (GUI), pytest (тесты).

## Описание функций и настроек

### Команды

|  Команда         | Описание |
|------------------|---|
| `ls [аргументы]` | Показать содержимое директории (заглушка на Этапе 1) |
| `cd [путь]`      | Сменить текущую директорию (заглушка на Этапе 1) |
| `exit`           | Выйти из эмулятора |

### Параметры командной строки

| Параметр | Описание |
|---|---|
| `--vfs` | Путь к физическому расположению VFS (ZIP-архив) |
| `--log` | Путь к CSV-файлу для логирования команд |
| `--script` | Путь к стартовому скрипту с командами |

### Логирование

Каждый вызов команды записывается в CSV-файл (если задан `--log`).
Формат: `дата и время, команда, ошибка`.

### Стартовый скрипт

Файл с командами (одна на строку). Выполняется автоматически при запуске.
Ошибочные строки пропускаются, скрипт продолжает работу.

### Скрипты для запуска

В папке `scripts/` лежат `.bat`-файлы для тестирования параметров:

| Файл | Что тестирует |
|---|---|
| `test_script.bat` | Только `--script` |
| `test_log.bat` | Только `--log` |
| `test_vfs.bat` | Только `--vfs` |
| `test_all.bat` | Все три параметра |

## Запуск

Из корня проекта:

    python -m src.main

Или двойной клик по `run.bat` (Windows).

## Запуск тестов

    pip install pytest
    python -m pytest tests/ -v

## Примеры использования

После запуска откроется окно с приглашением.
Введите команду и нажмите Enter.

Пример сессии:

    > ls
    Выполнена команда: ls, аргументы: []

    > ls -la /home
    Выполнена команда: ls, аргументы: ['-la', '/home']

    > cd /tmp
    Выполнена команда: cd, аргументы: ['/tmp']

    > unknown_command
    Ошибка: команда 'unknown_command' не найдена

    > exit
    (окно закрывается)
