## Общее описание

Эмулятор командной оболочки с графическим интерфейсом (GUI).
Имитирует работу командной строки UNIX-подобной ОС.
Работает с виртуальной файловой системой (VFS), загружаемой из ZIP-архива.

**Стек:** Python 3, Tkinter (GUI), pytest (тесты).

## Описание функций и настроек

### Команды

| Команда | Описание |
|---|---|
| `ls [-l] [-a] [-h] [имя]` | Показать содержимое директории. Флаги: `-l` — подробно, `-a` — включая скрытые, `-h` — размер в KB/MB |
| `cd <путь>` | Сменить директорию. Поддерживаются `/`, `.`, `..`, многоуровневые пути |
| `tac <файл>` | Вывести файл в обратном порядке строк |
| `head <файл>` | Вывести первые 10 строк файла |
| `chmod <режим> <файл>` | Изменить права доступа |
| `mv <источник> <назначение>` | Переименовать/переместить файл |
| `exit` | Выйти из эмулятора |

## Параметры командной строки

- `--vfs PATH` — путь к ZIP-архиву с виртуальной файловой системой
- `--log PATH` — путь к CSV-файлу для логирования команд
- `--script PATH` — путь к стартовому скрипту

## Примеры запуска

Пустая VFS:
    python -m src.main

VFS из ZIP:
    python -m src.main --vfs test_vfs.zip

VFS + лог + скрипт:
    python -m src.main --vfs test_vfs.zip --log mylog.csv --script scripts/vfs_test.txt

## Примеры использования

    > ls -la
    d644      -  sub
    -644      4  a.txt

    > cd level1/level2
    > cd ../..

    > tac a.txt
    > head a.txt
    > chmod 755 a.txt
    > mv a.txt renamed.txt

## Формат CSV-лога

    datetime,command,error
    2026-09-28 11:37:47,ls,
    2026-09-28 11:37:51,bad_cmd,команда не найдена

## Запуск тестов

    pip install pytest
    python -m pytest tests/ -v

## Логирование

Каждый вызов команды записывается в CSV-файл (если задан `--log`).
Формат: `дата и время, команда, ошибка`.

## Стартовый скрипт

Файл с командами (одна на строку). Выполняется автоматически при запуске.
Ошибочные строки пропускаются, скрипт продолжает работу.
